# @leaguelive/reporter-app

LeagueLive's on-the-ground reporter app (React Native/Expo). Lets field reporters submit live match events and scores to `backend`.

## Scripts

- `npm start` — start the Expo dev server
- `npm run android` / `npm run ios` / `npm run web`
- `npm run lint`

See [../../docs/SRS.md](../../docs/SRS.md) for functional requirements.
