# @leaguelive/fan-app

LeagueLive's fan-facing mobile app (React Native/Expo). Mobile counterpart to `fan-web` — lets fans follow live scores, schedules, and league content from `backend` on iOS/Android.

## Scripts

- `npm start` — start the Expo dev server
- `npm run android` / `npm run ios` / `npm run web`
- `npm run lint`

See [../../docs/SRS.md](../../docs/SRS.md) for functional requirements.
