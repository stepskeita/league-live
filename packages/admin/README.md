# @leaguelive/admin

LeagueLive's admin dashboard (Next.js). Used by league/tournament organizers to manage competitions, teams, and reporters, and to moderate live data before it reaches `fan-web`.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` / `npm start` — production build and serve
- `npm run lint`

See [../../docs/SRS.md](../../docs/SRS.md) for functional requirements.
